# Zalingei Digital Library

مكتبة زالنجي الإلكترونية العامة هي منصة عربية تهدف إلى نشر المعرفة والثقافة والكتب الإلكترونية بشكل واضح ومفيد ومناسب للمستخدم العربي.

## ما الذي يحتويه المشروع؟
- صفحة رئيسية
- صفحة "من نحن"
- صفحة "الكتب"
- صفحة "المقالات"
- صفحة "الكتب الجديدة"
- صفحة "الأسئلة الشائعة"
- صفحة "تواصل معنا"
- صفحة "سياسة الخصوصية"
- صفحة "الشروط والأحكام"
- ملف `robots.txt`
- ملف `sitemap.xml`
- ملف `style.css`

## الهدف
دعم القراءة، الثقافة، والمعرفة في بيئة رقمية سهلة ومريحة للمستخدم.

## التشغيل
افتح الملف `index.html` مباشرة في المتصفح، أو قم بنشر المشروع على GitHub Pages.
